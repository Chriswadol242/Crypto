# 🚀 APEX - Démonstration du Site Web 3D

## 🎯 Aperçu du Projet

**APEX** est un site web 3D moderne et interactif créé pour concurrencer Nike. Il présente une marque fictive de chaussures de sport avec une expérience utilisateur immersive utilisant les dernières technologies web.

## 🌟 Fonctionnalités Principales Réalisées

### ✅ Identité de Marque Complète
- **Nom** : APEX (Performance Redéfinie)
- **Palette de couleurs** : Orange (#ff6b35) et Noir (#1a1a1a)
- **Typographie** : Inter (moderne et lisible)
- **Slogan** : "Performance Redéfinie"

### ✅ Éléments 3D Interactifs
- **Scène héro 3D** avec chaussure rotative et particules
- **Vitrine produits** avec 3 modèles de chaussures en 3D
- **Visualisation technologique** avec animations orbitales
- **Interactions souris** pour contrôler les rotations

### ✅ Animations Avancées
- **GSAP** pour transitions fluides
- **ScrollTrigger** pour animations au défilement
- **Compteurs animés** pour les statistiques
- **Effets de parallaxe** sur les formes géométriques

### ✅ Design Responsive
- **Mobile-first** avec menu hamburger
- **Grilles adaptatives** pour tous écrans
- **Optimisations tactiles** pour mobile/tablette

## 📊 Performance & Optimisations

### ✅ Optimisations Incluses
- **Lazy loading** des ressources 3D
- **Debouncing** des événements
- **Cleanup** automatique Three.js
- **Responsive images** et assets
- **Compression** des géométries

### 🎯 Métriques Cibles
- **FCP** : < 2s (First Contentful Paint)
- **LCP** : < 3s (Largest Contentful Paint)
- **CLS** : < 0.1 (Cumulative Layout Shift)
- **FID** : < 100ms (First Input Delay)
